Here is a GitHub repo for Kyle Wolford and Becky Shofner's final project in CSE 4061. This project aims to investigate LLM hallucinations in legal contexts, and explores different methods to alleviate these hallucinations in AI-generated briefs. 
The code for naively generating briefs, as well as the first 2 hallucination reduction methods, can be found in Project.ipynb. 
We used the offial OpenAI API for ChatGPT models, and the NVIDIA NIM API for sourcing other models (in the mutli-model Find-Fix-Verify). Thus, to run this code, you will need both an OpenAI API key and a NVIDIA NIM API key. 
To run RAG, you will also need an OpenAI API key. The RAG.ipynb file contains code for sourcing/generating the ground-truth corpus as well as the actual retrieval and prompt augmentation. 
The illinois_med_mal_cases file on this Github contains 1000 of the json files generated by our web crawler- to get all 5000 (and thus the best performance), you will need to run the web crawler yourself. Github only allows 1000 items per folder.
If you do not care about overall performance, then running Rag.ipynb with just the 1000 files present on this repo would be sufficient to show the code works.
